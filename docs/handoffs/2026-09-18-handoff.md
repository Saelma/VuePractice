### 3-1. 착수 전 판정 (WA §1-3-1)

⚠ BACKLOG §P(기한 축)와는 겹치지 않는다 — 그쪽은 **설정값**(`application.yml`)의 기한이다.

| 쓰기 경로 | 판정 | 근거 |
|---|---|---|
| 이벤트 쿠폰 「받기」 | ✅ 기간을 본다 | `claimEventCoupon` → `issuableNow(now)` |
| 결제 때 쿠폰 사용 | ✅ | `redeem` → `isValidAt(now)` |
| 결제 때 세일가 | ✅ | 장바구니는 Redis 에 **수량만** 둔다 → `getCart` 가 캐시 없는 `findByIds` → `findActive(ids, now)` 로 매번 다시 계산 |
| 목록 세일 경계 60초 지연 | 이미 아는 것 | `products:list` TTL — 08-19 §2-2 가 고른 것 |
| 취소·반품 때 만료 쿠폰 복원 | 문제 아님 | 만료 쿠폰은 돌려받아도 만료다 |
| 🔴 **지난 기간으로 새로 만들기** — 세일 등록·수정, 쿠폰 생성 | **참** | 서버는 «끝 > 시작» 만 봤다 · 화면 날짜 칸에 `min` 없음 |
| 🔴 **끝난 세일 수정·삭제** | **참 · 성질이 다르다** | 화면이 「종료」 줄에도 두 버튼을 그렸다 · G-5 가 테이블을 고른 이유 ②(*«덮어쓰면 끝난 세일이 흔적 없이 사라진다»*)와 어긋남 |
