### 3-2. 🔴 변형 주입이 **「0건 잡힘」으로 위장했다**

13건이 **처음 돌린 순간부터 초록**이었다. 그건 아무것도 증명하지 않으므로(WA §변형주입)
규칙 하나당 하나씩 **변형 11개**를 넣었다.

| 표식 | 무엇을 망가뜨렸나 | 잡은 테스트 |
|---|---|---|
| `M1` | 탭 목록을 손으로 적은 것으로(반품완료 누락) | 1건 |
| `M2` | 탭을 눌러도 `status` 를 안 바꾼다 | 5건 |
| `M3` | 탭을 바꿔도 보던 쪽에 머문다 | 1건 |
| `M4` | 한 쪽뿐인데 페이지 이동을 그린다 | 1건 |
| `M5` | 첫 쪽에서 「이전」이 안 잠긴다 | 1건 |
| `M6` | 마지막 쪽에서 「다음」이 안 잠긴다 | 1건 |
| `M7` | 「다음」이 같은 쪽을 다시 부른다 | 2건 |
| `M8` | 쪽을 넘길 때 상태 필터가 빠진다 | 3건 |
| `M9` | 빈 목록이 늘 같은 말을 한다 | **0건 → 재주입 후 1건** |
| `M10` | 「전체 보기」가 아무것도 안 한다 | 1건 |
| `M11` | 로딩 스켈레톤을 안 그린다 | 1건 |

🔴 **`M9` 만 0건이었다.** 규약은 *"하나도 안 빨개지면 테스트가 아니라 그 규칙이 아무 데도 없는
것일 수 있다 — 그때는 테스트를 고치기 전에 운영 코드를 먼저 본다"* 고 한다. 그대로 봤더니
**운영 코드가 아니라 변형 자체가 잘못돼 있었다**:

표식 `<!-- M9 -->` 를 **Vue 태그의 속성 자리**에 넣었다 → `SyntaxError: Illegal '/' in tags` →
**템플릿 컴파일이 깨져** vitest 가 `src/views/OrderListView.test.js (0 test)` 를 냈다.
⚠ **집계는 «실패한 단언» 을 셌으므로 0 이었다** — 즉 «19건 중 아무도 안 잡았다» 와
«19건이 아예 안 돌았다» 가 **같은 숫자로 보였다.**

→ 표식을 `data-mut="M9"` 로(합법인 속성 자리) 바꿔 재주입하니 **의도한 그 테스트 하나**가 잡았다:
`🔴 탭 때문에 빈 것은 «어느 탭인지 대고» 말한다`.

🔴 **08-05 사고의 «반대 얼굴» 이다.** 그때는 잡혔는데 **크래시**로 보였고, 이번은 안 잡힌 것으로
보였는데 **애초에 안 돌았다.** 둘 다 «빨간 개수» 를 판정 근거로 쓰면 틀린다.
→ **규약으로 옮겼다**(WA §변형주입 — «실패 건수» 말고 «몇 건이 돌았나» 를 함께 본다).

⚠ **원복까지가 한 세트다**: `git checkout -- src/views/OrderListView.vue` 뒤
표식 잔재 `grep` **0** · `git status --short` 에 **테스트 파일만** 남은 것을 확인했다.
🔴 **오늘은 원복이 안전한 조건이었다** — 운영 코드를 한 줄도 안 고쳐서 `OrderListView.vue` 가
커밋 상태 그대로였다(07-31·08-04 사고가 난 조건이 **아니었다**는 것을 넣기 전에 확인했다).

### 3-3. 무엇을 지키게 됐나

**셋 다 «서버와 맞춰야 도는 배선» 이고, 틀려도 화면은 멀쩡히 그려진다** — 그래서 조용하다.

- **상태 탭**: 탭 목록이 `ORDER_STATUS_TEXT` 에서 나온다(손으로 적은 짝이 **아니다** — 서버에
  상태가 늘면 탭도 저절로 는다). 누르면 그 상태로 다시 부르고, 「전체」는 `status: null` 로 푼다.
  🔴 **탭을 바꾸면 첫 쪽으로 돌아간다** — 3쪽을 보다 옮겼는데 그 상태의 3쪽을 달라고 하면
  **빈 목록이 돌아오고 화면은 «주문이 없다» 고만 말한다**(고장으로 안 보이는 종류).
- **페이징**: 서버가 준 `page`·`totalPages`·`last` 를 **화면이 다시 셈하지 않는다.**
  한 쪽뿐이면 아예 안 그리고, 사람이 읽는 번호는 1부터다(0-based 를 그대로 적으면 «0쪽»).
  🔴 **쪽을 넘겨도 상태 필터가 따라간다** — 풀리면 «2쪽» 자리에 전체 주문의 2쪽이 와서
  **개수가 그럴듯해 안 들킨다.**
- **빈 목록**: «필터 때문에 빈 것» 과 «원래 없는 것» 이 다른 말을 한다(2026-07-20 §8-7 사고의 산물).
  ⚠ **그 판단은 `EmptyState` 주석에 적혀 있었는데 이 화면에서 지켜지는지는 아무도 안 보고 있었다.**
  「전체 보기」가 **실제로 필터를 푸는지**도 지킨다 — 죽으면 빈 화면이 막다른 길이 된다(J 축과 같은 모양).
  로딩 중에는 «없어요» 가 **안 스친다**(깜빡이면 없는 사고를 본 것이 된다).

  판단으로 안 뽑았다. **다만 이쪽은 몸통이 똑같다** — 셋째가 생기면 이게 먼저 뽑힐 자리다.
- 🔴 **변형 표식은 «주석이 합법인 자리» 에만 넣는다** — Vue 템플릿의 태그 속성 자리는 아니다
  (§3-2). ⚠ **이건 규약으로 옮겼다**(WA §변형주입) — 여기엔 경위만 있다.
