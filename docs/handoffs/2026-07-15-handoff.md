## 3. QueryDSL 재사용 프레임워크 (`global/querydsl/`)

- `@Cond(path, op, transform)` → `ConditionBuilder.of(Q, dto).build()`가 predicate 자동 생성.
- `Op`: EQ/NE/IN/CONTAINS/STARTS/ENDS/GOE/GT/LOE/LT, `Transform`: NONE/DATE_START/DATE_NEXT.
- `SortSupport.toOrders(sort, Q, allowed)` — **정렬 화이트리스트**. 허용 외 필드는 400(이전엔 500). notice 허용: createdAt·updatedAt·viewCount·title·author·pinned.
- `QueryDslSupport.page`(offset/limit+count). 탈출구: 조인·OR는 순수 QueryDSL로.

## 4. Redis 심화 (조회수 카운터 + 목록 캐시)

### 조회수 (`domain/notice/viewcount/`)
```
조회 POST /views → Redis INCR notice:view:{id}   (DB 무부하)
읽기            → DB view_count + Redis 미반영분
@Scheduled 30s  → GETDEL drain → addViewCount 벌크 반영 → Redis 정리
```

### 목록 캐시 (`CacheConfig`)
- `NoticeQueryService.search` → `@Cacheable("notices:list", key=조건+페이징)`, **TTL 60초**, JSON 직렬화(record+Instant, @class 타입정보).
- 작성/수정/삭제 → `@CacheEvict(allEntries)`. 조회수 증가는 캐시 안 건드림.
- **트레이드오프**: 목록의 조회수는 최대 60초 지연(상세는 실시간). 실측: miss→키생성, hit→역직렬화 정상, 작성 시 evict.

## 5. 인증 · 권한 (JWT + Spring Security)

- **JWT stateless**. Access(30분)+Refresh(14일), claim=role·nickname·jti. 시크릿 `.env` `JWT_SECRET`(HS384).
- **Redis**: 리프레시 `auth:refresh:{id}`(회전), 로그아웃 access 블랙리스트 `auth:blacklist:{jti}`.
- **Security**: STATELESS, `JwtAuthenticationFilter`→SecurityContext. 401은 `CustomAuthenticationEntryPoint` JSON.
- **@LoginUser AuthUser** 커스텀 리졸버로 토큰 사용자 주입(재파싱 없이 컨텍스트만). *JWT는 서명이지 암호화 아님 — payload 노출됨.*
- **글쓰기 로그인 필요**, 조회·조회수는 공개. **작성자=토큰 nickname**, 소유권=`Notice.authorId`(레거시 null).
- **소유권+ADMIN**: authorId==나 또는 role==ADMIN이면 수정/삭제 허용, 아니면 403. 관리자 승격은 DB `role='ADMIN'`+재로그인.

### 엔드포인트
- `/api/auth`: signup·login·refresh·logout·me
- `/api/members/me`: **닉네임 변경(PATCH /nickname)** · **비번 변경(PATCH /password, 현재확인+refresh무효화)** · **탈퇴(DELETE, access블랙리스트+refresh삭제+회원삭제, 글은 유지)**

## 8. 이커머스 도메인 (catalog · cart · order)  — 신규

게시판에서 만든 패턴(BaseTimeEntity·ConditionBuilder·@Cacheable·@LoginUser/ADMIN·ApiResponse)을 그대로 이식. **쇼핑 전체 루프**: 상품 → 장바구니 → 주문.

### catalog (`domain/catalog`)
- `Category` · `Product`(@ManyToOne 연관, **RAW(16) FK**) · `ProductStatus`(SELLING/SOLD_OUT/HIDDEN).
- 검색: `@Cond`(이름 CONTAINS·가격 GOE/LOE·상태 EQ) + **카테고리(연관)는 직접 QueryDSL**(ConditionBuilder "탈출구" 실전).
- 쓰기는 **관리자 전용**(`hasRole ADMIN`) + `CustomAccessDeniedHandler`(403 JSON), 조회 공개. 목록 `@Cacheable`.
- N+1 완화: `default_batch_fetch_size=100`(yml).

### cart (`domain/cart`) — Redis
- **Redis Hash** `cart:{memberId}`(field=productId, value=수량, TTL 30일). 담기 HINCRBY.
- 상품 정보는 **catalog 공개 서비스**(`ProductQueryService.findByIds`)에서 합성. `available`(판매중+재고) 계산, 삭제상품 자동정리. 로그인 필수.

### order (`domain/order`)
- `Order`(table **orders**, 예약어 회피) · `OrderItem`(**이름·가격 스냅샷**) · `OrderStatus`(ORDERED/CANCELLED).
- **결제**: 카트→주문, `ProductRepository.decreaseStock`(**원자적 UPDATE `WHERE stock>=qty`**, 오버셀 방지), 성공 시 카트 비움.
- 내 주문 목록·상세(본인만 `findByIdAndMemberId`→404), **취소**(ORDERED만, 재고 복원). 재고변경 시 상품 캐시 무효화.
- 도메인 간 참조는 **cart/catalog 공개 서비스로만**(리포지토리 직접참조 회피).

### image (`domain/image`) — 파일 업로드
- **`image_group`(앵커) 1—N `image`**. 여러 도메인(상품·공지·리뷰)이 `image_group_id`만 두면 이미지 재사용 → **polymorphic FK 회피**.
- `Product.imageGroupId`(느슨한 참조). 업로드 흐름: `POST /api/images`(관리자, 파일 저장+image row) → `{id, url}` → 상품 저장 시 `imageIds[]` → 그룹 생성·연결.
- `FileStorageService`: 디스크 저장(`/var/www/glassvue-uploads`), **검증 2단계 — 확장자 화이트리스트(jpg/png/gif/webp) + 매직바이트(시그니처)**. content-type·확장자·내용 위조 전부 차단. `size`→`file_size`(예약어).
- 조회: 목록은 그룹 이미지 **일괄조회(N+1 회피)**, 상세는 그룹 전체.
- 인프라(서버, git 밖): 업로드 디렉토리 + systemd **`ReadWritePaths`**(ProtectSystem=strict라 필요) + nginx **`location /uploads/`** + multipart 5MB.

### 프론트
- 상품 목록(검색: 이름·카테고리·상태·가격, 썸네일)/상세(이미지·장바구니 담기)/관리자 폼(이미지 업로드·썸네일)·카테고리 관리.

## 9. 트랩 · 교훈

- **springdoc 2.8.6→3.0.3**: Boot 4는 3.x (2.8.x는 런타임 `NoClassDefFoundError: TypeInformation`).
- **Boot 4 ObjectMapper 빈** 자동주입 안 됨 → EntryPoint에서 JSON 직접 작성으로 회피.
- **캐시 직렬화**: record+Instant는 JavaTimeModule + `@class` 타입정보 필요. (GenericJackson2JsonRedisSerializer(mapper)는 deprecated 경고 — 동작엔 문제없음)
- **`cp -i` 별칭** → `/bin/cp -f`. **파일 소유권** → root 생성분 `chown ecstel`, git/gradle/pnpm은 `runuser -l ecstel`. **샌드박스 `cd` 제거** → `-C`/`-p`.
- **role/nickname은 토큰에** 박혀 있어 DB 변경 후 재로그인/refresh 전엔 반영 안 됨. (관리자 승격 후 버튼 안 보임 → 재로그인으로 해결)
- **방화벽 timeout** = 포트 미개방(`firewall-cmd --permanent --add-port`).
- **Oracle 예약어**: `order`→테이블 `orders`, `size`→컬럼 `file_size`. (`ORA-01747`)
- **systemd ProtectSystem=strict**: 앱이 파일 쓰려면 `ReadWritePaths=<경로>` 추가해야 함(업로드 디렉토리).
- **파일 업로드 검증**: content-type·확장자 위조 가능 → **매직바이트(시그니처)가 최종 판정**.
