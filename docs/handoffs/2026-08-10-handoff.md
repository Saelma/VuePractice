## 2. 디스크 — VM 가상 디스크 확장 **종결** (BACKLOG `F-6`)

08-07 §10 이 *"절반 끝났다"* 로 끊겼던 자리다. **오늘 나머지를 다 밟았다.**

### 2-1. 이어받은 상태가 문서와 달랐다

문서(08-07 이월)는 `sda2` **29G** 를 물려줬는데 오늘 아침 실측은 **49G** 였다 —
`parted resizepart` + 재부팅이 이미 되어 있었다(`uptime -s` = **2026-08-10 07:55:14**).
⚠ **이월을 그대로 믿고 `parted` 를 또 제안했으면 이미 끝난 조작을 되풀이할 뻔했다.**
이월은 «어제까지의 상태» 지 «지금의 상태» 가 아니다 — **손대기 전에 다시 잰다.**

### 2-2. 남은 LVM 3단계 (사용자가 실행, CLAUDE.md — sudo 는 제안만)

```
sudo pvresize /dev/sda2
sudo lvextend -l +100%FREE /dev/mapper/rl-root
sudo xfs_growfs /
```

### 2-3. 실측 — 전후

| 항목 | 오늘 아침 | 지금 |
|---|---|---|
| `sda` | 50G | 50G |
| `sda2` | 49G | 49G |
| `rl-root` | **26G** | **46G** |
| `/` 크기 · 사용 · 여유 | 26G · 23G · **3.9G** | 46G · 23G · **24G** |
| 사용률 | **86%** | **49%** |

`sda` 50G = `sda1` 1G + `sda2` 49G 로 **남는 공간이 없다** — 여기서 더 늘리려면
**다시 호스트에서 VDI 를 키우는 것부터** 시작해야 한다(그 순서와 스냅샷 함정은 08-07 §10-2).

### 2-4. 캐시 1.9G 는 **안 지웠다** — 판단이 바뀌었다

이월에 *"sudo 캐시 정리 1.9G 도 아직 안 했다"* 가 있었지만, 실측하니 그대로다:
`/var/cache/PackageKit` **1.6G** · `/var/cache/dnf` **282M** · `~/.npm/_cacache` **108M**.

→ **지우지 않는다.** 08-07 §10 이 *"이건 또 찬다"* 로 이미 적었듯 근본은 PackageKit 의
선다운로드 설정이라 **지워도 되돌아온다.** 여유가 3.9G 였을 땐 1.9G 가 절반이었지만
24G 인 지금은 **8%** 다 — **같은 조작의 값어치가 여유에 따라 달라진다.**
⚠ `~/.npm/_cacache` 가 pnpm 만 쓰는데도 되살아나는 **원인은 여전히 모른다**(08-07 §10). 추측으로 적지 않는다.
