### 1-1. ⚠ 「주석만이 아니다」는 맞았지만, **이유가 이월이 적은 것과 달랐다**

이월은 *"결론에 따라 크기가 갈린다 — 주석 한 줄이면 5분, 표기를 넣으면 DTO·화면, 제외하면 쿼리까지"* 로
**크기의 갈래**를 적어 뒀다. 실제로 열어 보니 **갈래 하나가 이미 닫혀 있었다**:

🔴 **`ReviewQueryService.findForAdmin` 주석에 이미 판단이 적혀 있었다** —

⚠ **DESIGN §7 이 «나란히 쓰는 화면이라 생김새가 갈리면 안 된다» 고 적어 둔 그 짝**이다.
*"지워진"* 과 *"삭제된"* 이 섞이면 관리자는 **다른 상태로 읽는다.**
→ 문구를 `constants/labels.js` 의 **`DELETED_PRODUCT` 하나**로 모으고 세 화면이 그것을 쓴다.

⚠ **모은 것은 문구뿐이다 — 판정은 화면마다 다르고, 그게 맞다:**

| 화면 | 「상품이 사라졌다」를 어떻게 아나 | 왜 다른가 |
|---|---|---|
| 문의 | `type !== 'PRODUCT'` 를 먼저 가른 뒤 이름이 비면 | **일반 문의도 이름이 빈다** — 이름만으로는 못 가른다 |
| 리뷰 | **서버가 `productDeleted` 로 알려준다** | 리뷰는 상품 문의뿐이라 **이름이 빌 이유가 삭제 하나뿐**이다 |

→ 리뷰 쪽은 서버가 답할 수 있으므로 **판정을 서버 한 곳에** 뒀다(08-11 §13 ⓪ 의 결론과 같은 자리).

## 4. 구현

**백엔드**

- `AdminReviewResponse` — 틀린 `@param` 주석을 고치고 **`boolean productDeleted` 를 새로 실었다.**
  판정은 팩토리 한 줄(`productName == null`)이다.
- `ReviewQueryService.findForAdmin` — 「빈 이름」이 곧 «지워졌다» 라는 것과, 그 판정이 DTO 한 곳에
  있다는 것을 주석에 이었다. **동작은 안 바꿨다**(이미 맞게 동작하고 있었다).

⚠ **`null` 이 삭제 하나만 뜻하는지 따로 확인했다** — `ProductQueryService.findByIds` 는
`findAllById` 라 **상태로 거르지 않는다.** 즉 판매중지·숨김 상품도 이름은 그대로 실린다.
🔴 여기가 거짓말이 될 수 있는 유일한 자리라 **테스트로 못 박았다**(§5 의 넷째).

**프론트엔드**

- `ReviewAdminView.vue` — 상품 칸을 `cell-template` 으로 바꿔 `productDeleted` 면 「(지워진 상품)」을
  `muted` 로 그린다(DESIGN: 토큰만 쓴다).
- `constants/labels.js` **신설** — `DELETED_PRODUCT` 하나. `InquiryAdminView`·`SupportView` 의
  하드코딩 문자열 둘을 그것으로 바꿨다(§3).

⚠ **증상이 두 번 다 「끝에서」 나왔다** — 테스트는 다 돌았는데 결과 XML 이 **0개**라, 겉으로는
디스크·JVM·Gradle 버전 문제로 보인다. 실제로 디스크(24G 남음)와 메모리를 먼저 봤고 둘 다 멀쩡했다.

원인: **같은 `build/` 를 쓰는 Gradle 실행이 하나 더 돌고 있었다.**

```
$ ps -ef | grep "[G]radle"
69368  ... (데몬)
92994  ... -Dorg.gradle.internal.worker.tmpdir=.../build/tmp/test/work   ← 남의 테스트 워커
95996  ... (데몬)
```

한쪽의 `cleanTest`(또는 test 시작)가 **다른 쪽의 진행 중 결과 디렉터리를 지운다.** 변형 주입(§6)이
같은 워크트리에서 테스트를 돌리던 시간과 겹쳤다.

🔴 **여기서 배운 것은 「진단 명령」이 아니라 「무엇을 먼저 의심하나」다.** 실패 메시지가 파일 경로라
파일시스템을 의심하게 되는데, **판정은 «이 build 를 나 혼자 쓰고 있나»** 가 먼저다:

```bash
pgrep -af GradleWorkerMain      # 0 이어야 내 것만 돈다. 데몬이 여럿인 건 정상
```

⚠ **데몬 수를 세면 틀린다** — Gradle 데몬은 평소에도 2~3개 떠 있다. **워커**가 남의 실행의 표시다.
→ TROUBLESHOOTING §1 「빌드·테스트」에 증상 색인으로 넣었다.
