# 디자인 벤치마크 (고객 화면 리디자인 근거)

> **왜 이 문서인가.** 화면을 "좀 더 쇼핑몰답게" 바꾸려는데(사용자 요청, 2026-07-28), 아무 트렌디한 걸
> 가져오면 [`DESIGN.md`](../DESIGN.md)의 확고한 방향(절제된 무채색·CTA만 강조·콘텐츠 우선)과 충돌한다.
> 그래서 **지금 이 몰의 기능 구성에 맞는** 레퍼런스만 골라 근거로 박아둔다. 실제 화면 손댈 때 여기로 돌아온다.
> ⚠ **패턴만 참고**한다 — 외부로 아무것도 보내지 않고, 이미지·아이콘·서체는 우리 자산으로 재현한다(메모리 규약).

## 0. 전제 — 우리는 어떤 몰인가

- **다품목 카탈로그 커머스**(단일상품 DTC 랜딩이 아니다). 카테고리·옵션(variant)·검색·필터가 있다.
- **식품(과자 등)** 중심. 신선/식품 커머스의 문법이 맞는다.
- 이미 갖춘 것: 옵션별 재고, 쿠폰, 적립금·회원등급, 무료배송 임계(`amountUntilFree`), 리뷰·문의,
  주문·반품, 인앱 알림, 재입고 알림, 장바구니 배지, 찜.
- 제약: **웹폰트 금지**(LAN 내부라 CDN 안 뜸 — 시스템 폰트 + 자간·굵기로 위계). 강조색은 상태에만.

→ 그래서 **화려한 스낵 브랜드**(Magic Spoon·Cob 류, 원색+굵은 폰트)는 제외한다. 우리 미학과 정반대다.

## 1. 미학 앵커 — MUJI (우리 원칙과 거의 동일)

MUJI 온라인몰: **페이퍼 화이트 + 흑연색 잉크 + 단 하나의 강조색(빨강)**, 그마저 홈 전체에서 ~93번(대부분
1px 보더·작은 라벨)만 쓰고 **주요 버튼은 무채색**. 이게 `DESIGN.md §2`("거의 검정 강조 / 의미색은 상태에만")와
사실상 같다. MUJI 자체가 **식품 포함 다품목 카탈로그**라 구조도 맞는다.

- **Everlane** — 상품 카드가 **균일 정사각형**, hover 시 이미지 5% 확대 + "Add to Bag" 노출.
  → `DESIGN.md §7`이 원하는 카드 그리드의 구체적 인터랙션.

**훔칠 것:** 넉넉한 여백으로 품질감, 무채색 위에 이미지가 주인공, 강조는 CTA 한 곳, 카드 균일·절제된 hover.

## 2. 구조 레퍼런스 — 화면별 (한국 식품 커머스 맥락)

| 화면 | 벤치마크 | 훔칠 패턴 (우리 기능과 매핑) |
|---|---|---|
| **상품 목록** | 29CM · 무신사 | 상단 **필터 바** + 균일 카드(이미지·이름·가격·별점). 29CM의 여백·타이포 위계가 무채색과 맞음. → `카테고리`·별점 denorm·검색 |
| **상품 상세(PDP)** | 마켓컬리 · 무신사 | 큰 이미지 ↔ 우측 **구매 박스**(옵션+수량+담기/바로구매), 아래로 **리뷰 중심** 긴 스크롤. → `옵션(variant)`·`리뷰/문의`·`재입고 알림` |
| **장바구니·주문서** | 마켓컬리 | 항목 리스트 + **우측 고정 요약**(합계·배송비·무료배송까지 남은 금액·쿠폰·적립금). → 이미 `amountUntilFree`·쿠폰·적립금 보유 |
| **마이/혜택** | 마켓컬리 · 쿠팡 | 적립금·등급·쿠폰을 **혜택 허브**로 묶기. → `point`·`grade`·`coupon` |
| **관리자** | Shopify admin · 토스 대시보드 | 밀도 있는 표(DataGrid) 유지 + 셸만 토큰. → `DESIGN.md §6·§7` (B-12) |

## 3. 왜 이 조합인가

- **마켓컬리** = 식품 + 쿠폰/적립/배송 요약이 핵심 → 우리 쿠폰·적립금·무료배송 임계가 화면에 가장 자연스럽게 붙는다.
- **29CM/무신사** = 필터 많은 다품목 목록 + 리뷰 중심 PDP → 옵션·리뷰·문의 구조와 맞고 톤이 절제됨.
- **MUJI/Everlane** = "미니멀인데 싸구려로 안 보이게" 하는 여백·카드 규칙의 교과서 → 프로토타입 티 제거.

## 4. 적용 순서 (DESIGN.md §9 로드맵과 합침)

0. ✅ **토큰·셸**(색감 무신사식 검/흰 통일 + 폭 1280) — 2026-07-28.
1. ✅ **상품 목록 카드 그리드**(할인 뱃지·테두리 제거·밀도 4열) — 2026-07-28.
2. ✅ **상품 상세**(하단 스티키 서브탭 상세정보·리뷰·문의 + 구분선. 리뷰는 탭 뒤에 안 숨김=전환율) — 2026-07-28.
3. ✅ **장바구니·주문서** — 이미 우측 고정 요약 완성돼 있었음. 무료배송 진행바만 추가 — 2026-07-28.
4. ✅ **마이/혜택 허브**(/benefits: 적립금·등급 + 신규 쿠폰함) + **관리자 쿠폰 화면**(생성·발급) — 2026-07-28.
5. ✅ **관리자(B-12)** DataGrid 톤·카드 프레임·모던 룩(세로선 제거·헤더·tabular-nums) + **Pretendard 셀프호스팅** — 2026-07-28.

**→ 로드맵 종결.** 고객·관리자 화면 톤 통일 + Pretendard 적용 완료. 더 갈 여지(회원 상세 카드화, 뱃지 pill 등)는 필요해지면.

⚠ **대부분 이미 돼 있었다** — 착수 전 현재 화면을 먼저 읽어 "표→카드" 같은 헛손질을 막고 벤치마크 기준
폴리싱만 했다. 각 단계는 **화면 하나씩** 올려 눈으로 확인하고 넘어간다(WORKING-AGREEMENTS §5).
